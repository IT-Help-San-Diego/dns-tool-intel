DEVONagent Pro Plugin

Add intelligence-grade DNS security analysis to your DEVONagent Pro research workflows. Each query returns up to 13 enriched results — security reports, reconnaissance data, integrity-verified snapshots, and provenance metadata.

When a domain is analyzed through this plugin, you'll see a Plugin tag next to the domain in your analysis history.

  • 2. Covert Recon Report — full analysis in covert operations mode
  • 3. Observed Records Snapshot — reconstructed zone file, SHA-3-512 verified
  • 4. Covert Security Badge — scotopic-optimized embeddable badge

  • 12. Executive Report — board-ready executive summary
  • 13. Sources & Methodology — RFC citations, data sources, and scoring methodology

How It Works

When DEVONagent queries a domain through this plugin, it hits the /agent/search endpoint with ParseLinks: true. DNS Tool returns a single HTML page containing up to 13 hyperlinks. DEVONagent extracts each link as a separate search result, giving you direct access to every report, badge, export, and data artifact from one query.

The agentQuery placeholder in the engine URL is automatically replaced by DEVONagent with whatever domain you search for. Results are cached on first access and served fresh on subsequent requests through the standard analysis pipeline.

Building Your Own Plugin

DEVONagent Pro search plugins are JSON objects with a specific schema. The key fields:

FieldPurpose
EngineUrlThe search endpoint. Use agentQuery as a placeholder — DEVONagent replaces it with the user's search term.
ParseLinksWhen true, DEVONagent extracts every <a href> from the response as a separate result.
ResultsPerPageHow many results DEVONagent expects per page. Set this to match the number of links your endpoint returns.
KeywordArray of trigger words. DEVONagent may prioritize this plugin when queries contain these terms.
OperatorsBitmask controlling which search operators the plugin supports (e.g., phrase search, Boolean).
Start / OffsetPerPagePagination controls. For single-page results like DNS Tool, set Start: 0 and OffsetPerPage: 1.

For full documentation, see DEVONtechnologies.
