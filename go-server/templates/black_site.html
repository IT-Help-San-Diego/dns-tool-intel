{{icon "bug" "me-1"}} APT — Advanced Persistent Threats

These bugs orchestrated the whole operation against our codebase. They don’t just cause one problem — they corrupt trust in the entire system.

f65edf BSI-001: Covert Mode Is a Page Navigation, Not a Toggle

Captured by T002 (Ghost Protocol), T005 (The Architect) • src/js/main.js:593-606

On the Engineer’s Report, pressing the covert button doesn’t toggle — it navigates to /analysis/{'{'}id{'}'}/view/C (full page load). Pressing it again navigates back. User loses scroll position, loading state resets, and the interaction feels fundamentally broken. On non-results pages, the same button does a client-side class toggle. Two completely different behaviors behind the same red button.

“When you press the red button it works. But then if you hit it again, nothing happens.”

Core interaction feels broken. Conference demo killer.

Detained

1d4705 BSI-002: Glass Treatment Only on Posture Cards

Captured by T002, T004 (Design Forensics) • src/css/custom.css:1087-1135

The glassmorphism CSS selectors are extremely specific — only cards with the exact class combo card.border-{'{'}status{'}'}.bg-{'{'}status{'}'}.bg-opacity-10 get the treatment. Confidence, Currency, and Domain Summary cards all use different class patterns. Result: the posture card is alive with glass and hover-lift. Everything around it is a dead slab.

Inconsistent visual language. It looks like we started a design system and got tired halfway through.

Detained

cffa37 BSI-003: Golden Ratio Claims Without Mathematical Evidence

Captured by T005 (The Architect)

The scan topology SVG delivers (320/198 ≈ 1.616 ≈ φ). But the CSS type scale and spacing system uses ad hoc values: 0.75, 0.8, 0.85, 1.1, 3.5, 2.5rem. These are not Fibonacci numbers. They’re not derived from φ. If someone at a conference opens DevTools and checks the math, the claim becomes a liability instead of a feature.

Intellectual honesty risk. The topology claim is real. The system-wide claim is not.

Detained

d95e9a BSI-004: No prefers-reduced-motion in CSS

Captured by T004 (Design Forensics), T005 (The Architect) • Entire src/css/custom.css

Users who set “Reduce Motion” in their OS still see every transition, transform, and animation. JavaScript handles the topology SVG SMIL animation, but CSS transitions are completely unprotected. WCAG 2.1 SC 2.3.3 requires this. It’s not optional.

Hard accessibility compliance failure. Any accessibility auditor would flag this instantly.

Detained

12de6c BSI-005: Stats Label — 2.1:1 Contrast (WCAG Requires 4.5:1)

Captured by T003 (Perimeter Sweep) • stats.html:158-159

.stats-confidence-metric-label { color: #484f58; } on #0d1117 background. Contrast ratio: 2.1:1. WCAG AA requires 4.5:1 for normal text. Less than half the required ratio. Users with low vision cannot read it at all.

This isn’t a style preference — this is text that cannot be read. On a page where the numbers are the entire point.

Detained

a37166 BSI-006: Compare Select — Keyboard Users Locked Out

Captured by T003 (Perimeter Sweep) • compare_select.html:170-219

Domain comparison rows use click handlers on bare <tr> elements. No tabindex. No role="button". Keyboard-only users literally cannot reach or activate these rows. WCAG 2.1 Level A — the absolute baseline.

An entire feature of the product is inaccessible to keyboard-only users, screen reader users, and users with motor disabilities.

Detained

b1951c BSI-007: Broken SVGs on Architecture Page

Captured by T001 (SquirrelScan) • /architecture page

Two SVG diagrams return 404: drift-notification-pipeline.svg and github-issues-triage.svg. These are on the page specifically designed to demonstrate our engineering discipline and system design rigor.

Broken images on the page that’s supposed to prove we build things carefully. The irony is not lost.

Detained
